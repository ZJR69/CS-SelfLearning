## 卡点与解答

- **"建模"是什么?** 从带标注数据学可迁移到新样本的判断规则。由此推出 PassengerId 这类 ID 不参与建模:对新乘客无泛化价值。
- **pandas dtype ≠ 统计类型**:Pclass 存成 int64 仍是有序类别型;判断类型看语义,不看存储。
- **票号重复 ≠ 错误**:整行重复才是采集事故;Titanic 的重复票号是家庭/团体票,不能删。
