# 单元：控制流与跳转（Control Flow and Jumps）

- 所属课程：计算机系统（ICS）
- 状态：🟡 进行中
- 开始日期：2026-10-13　完成日期：

## 学习目标

1. 理解控制流的本质：对 PC（%rip）的有计划修改；标号→相对偏移的位置无关思想
2. 掌握四个标志位（CF/OF/ZF/SF）的置位条件，知道谁设标志、谁不设（mov/lea 不设）
3. 分清有符号（jg/jl）与无符号（ja/jb）两套跳转后缀，会算机器码里的跳转偏移
4. 认出 if-else / do-while / while / for / switch / cmov 的汇编指纹，能反推 C 结构
5. 会用 gdb 断点、单指令执行、查看标志位（为 BombLab 铺路）
