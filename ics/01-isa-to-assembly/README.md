# 单元：从 ISA 到汇编（From ISA to Assembly）

- 所属课程：计算机系统（ICS）
- 状态：🟡 进行中
- 开始日期：2026-10-12　完成日期：

## 学习目标

1. 掌握应对复杂的两大思想武器：分治与抽象（接口），知道抽象会泄漏
2. 理解 ISA 作为软硬件契约：CPU = 一堆状态 + 改状态的操作
3. 分清 CISC 与 RISC 的根本区别（访存指令个数），了解六大体系结构
4. 会读 x86-64 AT&T 汇编：三条规矩、mov、寻址公式、计算/测试指令
5. 能逐行读懂简单汇编程序（含跳转），会用 lea 一条指令做"乘加"

## 前置要求

- C 语言基础（函数、位运算、for 循环）
- 对应课堂课件：《4-assembly-1 · 化繁为简，得意忘言——从ISA到汇编》（魏钧宇，共 74 页；课件有版权不上传，讲义中标注了对应页码）
