B

分治：切在"依赖最少"的缝上

最经典的分治是归并排序（p7），三步：

拆到只剩 1 个元素，天然有序。

切得好 · 高内聚低耦合 切得烂 · 藕断丝连
每块职责单一，一句话说清管什么 一块干好几件事，说不清职责
块间只有少量清晰的接口往来 块间到处互相调、共享内部状态
改一块，不牵动其他块 动一处，全线连锁崩
信息隐藏（Parnas 1972）

每个模块把"最可能变的决定"藏在自己内部，别人只看不变的接口。

C

抽象 = 一纸契约

每个块仅对外给出"我保证做到什么"的承诺（p10）：

  • 前置条件：你要给什么
  • 后置承诺：我保证返回什么
  • 不承诺的部分：怎么做到、有多快

以 sort() 为例：你信的是"返回升序结果"这个承诺。它现在用快排、相等元素恰好这个顺序，属于实现细节——哪天库升级就坑你。把不承诺的部分当成随时会变，代码才稳。

接口不变，两侧就能独立升级（p11）：

  • 下层换血：机械硬盘换成固态硬盘，read/write 没变，程序一行不改
  • 上层换血：同一套 x86-64 指令集，Word、游戏、编译器都能跑
D

分层抽象：只和邻层说话

接口层层叠加（p12）：

分层三条铁律：

  1. 你只调用正下方那层的接口
  2. 你只向正上方那层提供接口
  3. 不许越层抄近道，否则分层就废了

越层调用一时爽，日后重构火葬场。

好的抽象长什么样

五条标准（p13）：

标准 含义
简单 动词越少越好，文件就 open/read/write/close 四个
完备 该做的事都能表达，不逼人抄近道
正交 一个接口只干一件事，像乐高任意拼
稳定 契约不轻易改，改了砸掉所有上层
难以误用 默认就是对的用法，易错路径走不通

最高境界：让人以为下面很简单——哪怕下面复杂到没人看得懂。

无处不在的抽象

计算机的历史就是层层加抽象的历史（p15）：

  1. 手工接线(最早)ENIAC改程序=重新插线，人直接面对硬件
  2. 机器码/汇编第一层软件抽象助记符代替 0/1，本讲 Part C 讲它
  3. 高级语言C / Python不用管寄存器，编译器替你翻译
  4. 操作系统进程 / 文件 / 虚存把裸硬件封成好用的服务
  5. 框架/云(最晚)PyTorch / K8s连机器在哪都不用管

操作系统的三大抽象（p16）：

抽象 藏起的真相 给你的幻觉 背后机制
进程 CPU 核很少 我独占一台 CPU 上下文切换/调度
虚拟内存 物理内存有限且共享 我独享连续大地址空间 页表/地址翻译
文件 设备五花八门 统一的字节流 文件系统/设备驱动

网络五层同理（p17）：逻辑上层对层直接对话，实际数据下行到物理层再上行。用 WiFi 还是宽带，不影响浏览器代码。编译器靠中间表示 IR（p18）：换语言只写新前端，换 CPU 只写新后端。今天的神经网络、大模型 API、Agent、云服务，仍是同一招（p19）。

G

抽象泄漏：本讲最锋利的一刀

当性能、错误、边界情况出现时，下层的真相暴露出来，编程者被迫理解本该藏起来的细节（p21）。

Spolsky 定律（2002）

所有非平凡的抽象，在某种程度上都会泄漏。

三个典型泄漏（p22）：

承诺 漏出的真相 后果
内存都一样快 缓存让访问顺序决定快慢 按行/按列扫二维数组差几倍
int 就是数学整数 定长补码会溢出 mid=(low+high)/2 在 JDK 潜伏 9 年
读文件一定成功 会断、会卡、只读半截 不查 read 返回值就是埋雷

算术接口的补充条款一直在生效、从未被提起（p23）：

  • 整数越界回绕：INT_MAX 再 +1 变成 -2147483648
  • 浮点没有结合律：(a+b)+c ≠ a+(b+c)，并行求和换顺序结果就变

系统调用 read/write 的三个坑（p24）：可能只读一部分要循环再读；返回 -1 且 errno==EINTR 是被信号打断需重试；错误信息在全局 errno。繁琐到要《UNIX 环境高级编程》几百页专讲正确用法。

正确应对

不是"别用抽象"，而是"知道它会在哪漏"——懂下一层，才能用好这一层。汇编，就是往下钻的那一层。

思想清单与三句话

武器 出处 一句话
分治 古老工程智慧 大问题拆小问题，各个击破
信息隐藏 Parnas 1972 把最易变的决定藏进模块内部
关注点分离 Dijkstra 一次只想清楚一件事
接口/实现分离 抽象数据类型 ADT 用它的人只看接口，不看实现
再加一层间接 Wheeler 名言 几乎所有问题都能靠加一层解决
抽象泄漏 Spolsky 2002 非平凡的抽象，都会在某处漏

最重要的三句话（p27）：

  1. 分治：横竖切开，复杂度被关进每一块内部
  2. 抽象=接口：藏起怎么做、只露怎么用，接口不变则两侧独立升级
  3. 抽象会泄漏：用好抽象的前提是懂下一层

层层抽象里有一层最重要、最稳定、承上启下——ISA。下一轮专门讲它。
