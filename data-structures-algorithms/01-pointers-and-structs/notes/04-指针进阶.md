# 06 指针进阶：函数传参 + 指针与数组

> 上一章学会了 `&` 和 `*` 的基本操作。这一章回答一个关键问题：**指针到底有什么用？** 两个最重要的用途一次讲透。

---

## 一、指针做函数参数：让函数能"隔空改人"

### 先看一个经典失败案例

想写一个函数交换两个变量：

```c
void swap(int x, int y) {
    int t = x;
    x = y;
    y = t;
}

int main(void) {
    int a = 1, b = 2;
    swap(a, b);
    printf("%d %d\n", a, b);   // 还是 1 2！交换失败
}
```

**为什么失败？** C 语言函数参数是**值传递**——`swap(a, b)` 只是把 a、b 的**副本**给了 x、y。函数里改的是副本，原件纹丝不动。

### 指针版：把"地址"给函数

```c
void swap(int *x, int *y) {   // 参数是两个地址
    int t = *x;               // 顺着地址读
    *x = *y;                  // 顺着地址写
    *y = t;
}

int main(void) {
    int a = 1, b = 2;
    swap(&a, &b);             // 把 a、b 的地址传过去
    printf("%d %d\n", a, b);  // 2 1 ✅ 交换成功！
}
```

原理：`swap` 拿到 a、b 的门牌号，就能直接操作原件。

### 记忆规律

| 你想让函数做什么 | 参数怎么传 |
|------------------|-----------|
| 只是**用一下**变量的值（如打印） | 直接传值：`f(a)` |
| 让函数**修改**你的变量 | 传地址：`f(&a)`，函数内用 `*` 读写 |

> 一个函数想"返回"多个结果时也靠这个——比如 `void min_max(int arr[], int n, int *pmin, int *pmax)`，通过两个指针带回最小值和最大值。

## 二、指针与数组：一枚硬币的两面

### 数组名的秘密

```c
int arr[5] = {10, 20, 30, 40, 50};
```

**数组名 `arr` 在绝大多数场合等价于"首元素的地址"**，即 `&arr[0]`：

```c
int *p = arr;        // ✅ 等价于 int *p = &arr[0];
printf("%d\n", *p);  // 10
```

### 指针运算：+1 是"下一个元素"，不是"下一个字节"

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;

printf("%d\n", *p);       // 10 —— p 指向 arr[0]
printf("%d\n", *(p + 1)); // 20 —— p+1 指向 arr[1]
printf("%d\n", *(p + 2)); // 30
```

`p + 1` 不是地址数字加 1，而是**向前走一个 int（4 字节）**。编译器根据指针类型自动算好步长——这就是"指针必须带类型"的原因之一。

### 重要等价关系（背下来）

```
arr[i]  ≡  *(arr + i)  ≡  *(p + i)  ≡  p[i]
```

所以遍历数组有两种完全等价的写法：

```c
// 下标法（你已经会的）
for (int i = 0; i < 5; i++) {
    printf("%d ", arr[i]);
}

// 指针法
int *p = arr;
for (int i = 0; i < 5; i++) {
    printf("%d ", *(p + i));
}
```

> 初学建议：理解指针法是底层原理，**写代码优先用下标法**（可读性好）。但读别人的代码、处理字符串时，指针写法到处都是，必须看得懂。

### 数组传参的真相

```c
int sum(int arr[], int n) {   // 看着像传数组，其实 arr 就是 int*
    int s = 0;
    for (int i = 0; i < n; i++) s += arr[i];
    return s;
}
```

**数组作为函数参数时，实际传的是首元素地址**（退化为指针）。所以：
- 函数里改 `arr[i]` 会改到原件（和指针传参一个道理）
- 必须额外传长度 `n`——指针不知道数组有多长

## 三、字符串 = 字符数组 + `char *`

```c
char s[] = "hello";
```

- `s` 是数组，本质就是 `char` 序列，以 `'\0'` 结尾
- `s` 作为数组名，等价于 `&s[0]`，即 `char *`

所以字符串处理函数全是指针参数：

```c
int my_strlen(const char *s) {   // const 表示"只读，不修改"
    int len = 0;
    while (s[len] != '\0') {     // 遇到结尾的 \0 停止
        len++;
    }
    return len;
}
```

> `const char *s` 读法："指向只读字符的指针"——函数承诺不修改字符串内容。传字符串给别人用时加 `const` 是好习惯。

## 四、常见坑速查

| 坑 | 例子 | 后果 |
|----|------|------|
| 野指针解引用 | `int *p; *p = 1;` | 崩溃/数据损坏 |
| 数组越界 | `arr[5]`（大小才 5） | 读到垃圾或崩溃，**C 不检查！** |
| 返回局部变量地址 | 函数里 `int x; return &x;` | 函数结束 x 销毁，地址成悬空指针 |
| 混淆 `*p++` | 等价于 `*(p++)` 不是 `(*p)++` | 逻辑错误（优先级：++ 高于 *） |

---

## 五、一句话小结

> **函数想改外部变量 → 传地址。数组名 ≈ 首元素地址 → 数组传参就是传指针。`arr[i]` 就是 `*(arr+i)` 的语法糖。**

## 六、自测问答（先自己答，答案在最后）

**Q1**　为什么 `swap(a, b)`（传值）交换失败，而 `swap(&a, &b)`（传地址）成功？

**Q2**　`int arr[5]; int *p = arr;` 之后，`p + 1` 和 `&arr[1]` 是什么关系？`p + 1` 的地址数字比 `p` 大多少字节？

**Q3**　下面函数能被调用方看到修改结果吗？为什么？

```c
void set_zero(int arr[], int n) {
    for (int i = 0; i < n; i++) arr[i] = 0;
}
```

**Q4**　`char s[] = "abc";` 数组 s 实际占几个字节？画出来。

**Q5**（挑错）下面代码有什么问题？

```c
int *get_num(void) {
    int x = 42;
    return &x;
}
```

---

<details>
<summary>💡 答案（写完再点开）</summary>

**A1**　传值时函数收到的是副本，改副本不影响原件；传地址时函数拿到原件的"门牌号"，用 `*` 直接读写原件。

**A2**　`p + 1` 和 `&arr[1]` 完全等价（都指向 arr[1]）。int 占 4 字节，所以地址数字大 4。

**A3**　能。数组传参本质是传首元素地址，`arr[i] = 0` 改的就是调用方的原数组。这正是"指针传参可修改原件"的体现。

**A4**　4 个字节：`'a' 'b' 'c' '\0'`。字符串字面量自动带结尾的 `\0`。

**A5**　返回了局部变量的地址。函数结束后 x 的内存被回收，调用方拿到的指针悬空，解引用是未定义行为。改法：用参数指针带回结果，或用 malloc（第 07 章讲）。
