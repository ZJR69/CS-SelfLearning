## 一、知识地图

```
结构体                          指针
─────────                      ─────────
定义新类型                      内存 = 带地址的柜子
struct Student { ... };        int *p = &a;
                               & 取地址 / * 解引用
访问：变量.成员                 军规：先指向合法内存再解引用
初始化：{...} 或 {.x=...}
        │                            │
        │      合体                  │
        └───────────┬────────────────┘
                    ▼
        struct Student *p = &s;
        p->score  ≡  (*p).score

        传参三原则：
        · 只读      → const struct Xxx *p
        · 要改原件  → struct Xxx *p
        · 数组传参  → 本质是首元素指针，必须另传长度

        返回指针：
        · 可以 → 数组元素地址、malloc 来的内存
        · 不行 → 函数内局部变量的地址（悬空！）

        malloc/free：
        · malloc(sizeof(T)) 申请 → 检查 NULL → 使用 → free → 置 NULL
```

## 二、易混点对照表（考前速查）

| 写法 | 含义 |
|------|------|
| `int *p;` | 声明：p 是 int 指针 |
| `*p = 5;` | 使用：解引用，往 p 指的地方写 5 |
| `s.name` | 结构体**变量**访问成员 |
| `p->name` | 结构体**指针**访问成员 |
| `arr[i]` | ≡ `*(arr + i)` |
| `&arr[i]` | ≡ `arr + i` |
| `f(a)` vs `f(&a)` | 传值（改不了原件）vs 传址（能改） |

| 坑 | 一句话 |
|----|--------|
| 野指针 | 没初始化别解引用，先 `= NULL` |
| 悬空指针 | 别返回局部变量地址；free 后置 NULL |
| 数组越界 | C 不检查，自己守住下标范围 |
| 字符串赋值 | 数组名不能 `=`，用 `strcpy` |
| 结构体定义 | 末尾分号别丢 |
