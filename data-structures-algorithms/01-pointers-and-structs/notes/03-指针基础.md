# 04 指针基础

> 这是整个 C 语言最重要、也最容易劝退的一章。慢慢来，把每个例子都在脑子里过一遍。

## 一、先建立心智模型：内存 = 一排带门牌号的柜子

你的电脑内存（RAM）可以想象成一排**连续编号的柜子**：

```
地址:    1000   1001   1002   1003   1004  ...
        ┌────┬────┬────┬────┬────┐
内容:    │ 42 │ ?? │ ?? │ ?? │ 7  │ ...
        └────┴────┴────┴────┴────┘
```

- 每个柜子有**地址**（门牌号，比如 1000）
- 每个柜子里存着**内容**（一个值）

当你写 `int a = 42;` 时，编译器做了三件事：
1. 找几个空柜子（`int` 占 4 个字节，即 4 个柜子）
2. 把 42 放进去
3. 给这块区域起个名字叫 `a`

**`a` 是名字，地址才是位置。** 用 `&a` 可以问到它的地址：

```c
int a = 42;
printf("%d\n", a);    // 42      —— a 的值
printf("%p\n", &a);   // 0061FF1C —— a 的地址（%p 打印地址，每次运行可能不同）
```

> `&` 读作"取地址"。`&a` = "变量 a 的地址"。

---

## 二、指针变量 = 专门存地址的变量

普通变量存"值"，指针变量存"地址"。

```c
int a = 42;
int *p = &a;    // p 是一个指针，里面存着 a 的地址
```

逐部分拆解 `int *p = &a;`：
- `int *` —— 声明这是一个"指向 int 的指针"（不是 int，是 int 的地址）
- `p` —— 指针变量的名字
- `= &a` —— 初始化为 a 的地址

内存里的关系：

```
   p                    a
┌────────┐          ┌────┐
│ 1000   │ ───────> │ 42 │
└────────┘          └────┘
 存的是地址            存的是值
```

> ⚠️ 读法：`int *p` 从右往左读——"p 是一个指针，指向 int"。
> `*` 在这里是**类型的一部分**，表示"指针"。下面会看到它的第二种含义。

---

## 三、解引用 `*`：顺着地址找到那个柜子

有了地址，就能"顺着门牌号找到柜子，读写里面的值"。这个操作叫**解引用**，也用 `*`：

```c
int a = 42;
int *p = &a;

printf("%d\n", *p);   // 42 —— 顺着 p 存的地址，找到 a，读出值
*p = 100;             // 顺着 p 存的地址，找到 a，改成 100
printf("%d\n", a);    // 100 —— a 被改了！
```

**关键点：通过指针可以修改"别人家的变量"。** 这是指针最核心的能力，后面函数传参全靠它。

### `*` 的两种含义（新手最容易混）

| 场景 | 写法 | 含义 |
|------|------|------|
| **声明时** | `int *p;` | p 是一个"指向 int 的指针"（类型说明） |
| **使用时** | `*p = 100;` | 解引用：顺着地址找到目标，读写它 |

同一个符号，两个角色。判断方法：看 `*` 前面有没有类型名。`int *p` 是声明；单独 `*p` 是使用。

## 四、完整例子

```c
#include <stdio.h>

int main(void) {
    int a = 42;
    int *p = &a;

    printf("a 的值   : %d\n", a);
    printf("a 的地址 : %p\n", &a);
    printf("p 的值   : %p\n", p);     // 就是 a 的地址
    printf("*p 的值  : %d\n", *p);    // 42

    *p = 99;                          // 通过指针改 a
    printf("改后 a   : %d\n", a);     // 99

    // 指针也可以改指别人
    int b = 7;
    p = &b;                           // p 现在指向 b 了
    *p = 8;
    printf("b = %d, a = %d\n", b, a); // 8, 99（a 不受影响）
    return 0;
}
```

## 五、三条军规（血泪教训，先背下来）

### 军规 1：指针必须先指向合法内存，才能解引用

```c
int *p;      // 声明了但没初始化！p 里是随机垃圾地址
*p = 42;     // ❌ 灾难：往随机地址写数据，可能直接崩溃
```

未初始化的指针叫**野指针**。要么定义时就赋值，要么先指向 NULL：

```c
int *p = NULL;   // NULL 表示"现在谁都不指"，是安全的空状态
if (p != NULL) {
    *p = 42;     // 用之前检查是好习惯
}
```

### 军规 2：指针类型要和指向的类型匹配

```c
int a = 42;
int  *p1 = &a;   // ✅ int* 指向 int
char *p2 = &a;   // ⚠️ 类型不匹配，编译器会警告
```

### 军规 3：`&` 和 `*` 是逆操作

```c
int a = 42;
int *p = &a;
printf("%d", *p);       // 42
printf("%d", *&a);      // 42 —— 先取地址再解引用，回到原点
```

---

## 六、一句话小结

> **指针 = 存地址的变量。`&` 取地址，`*` 顺着地址读写目标。通过指针可以隔空修改别的变量。**

## 七、自测问答（先自己答，答案在最后）

**Q1**　`int *p;` 和 `*p = 5;` 里的两个 `*` 含义一样吗？分别是什么？

**Q2**　下面代码输出什么？

```c
int a = 10, b = 20;
int *p = &a;
*p = *p + 5;
p = &b;
*p = *p + 5;
printf("%d %d\n", a, b);
```

**Q3**　下面代码有什么问题？

```c
int *p;
printf("%d\n", *p);
```

**Q4**　想打印变量 `x` 的地址，`printf` 的格式符应该用什么？

---

<details>
<summary>💡 答案（写完再点开）</summary>

**A1**　不一样。`int *p;` 里的 `*` 是类型说明（p 是 int 指针）；`*p = 5;` 里的 `*` 是解引用操作（读写 p 指向的目标）。

**A2**　`15 25`。第一处 `*p + 5` 时 p 指向 a，a 变 15；然后 p 改指 b，b 变 25。

**A3**　野指针。p 没初始化就解引用，行为未定义（可能崩溃、可能输出垃圾值）。正确做法：`int *p = NULL;` 或定义时立即指向合法变量。

**A4**　`%p`，例如 `printf("%p", &x);`（有的编译器接受 `%p` 配 `(void*)&x` 更严谨，初学用 `%p` 即可）。
