# 03 结构体进阶：数组 + 嵌套

基础学完了：会定义、会初始化、会用 `.` 访问。但实际程序里几乎不会只管理 1~2 个学生——所以这一阶段解决两个问题：

1. **结构体数组**：一次管理一批结构体
2. **结构体嵌套**：结构体里面再装结构体

---

## 一、结构体数组

### 为什么需要？

100 个学生，你总不能写 `s1, s2, ..., s100`。答案和你想的一样：**数组**。

```c
struct Student {
    char name[20];
    int  age;
    int  score;
};

struct Student class[3] = {
    {"张三", 18, 95},
    {"李四", 17, 88},
    {"王五", 19, 77}
};
```

注意看初始化写法：**外层花括号是数组，每个内层花括号是一个结构体**。

### 访问方式：`数组[下标].成员`

```c
class[0].score = 100;              // 改第一个学生的成绩
printf("%s", class[2].name);       // 打印第三个学生的名字
```

口诀：先取数组元素（得到结构体），再点成员。

### 配合 for 循环遍历（这才是威力所在）

```c
for (int i = 0; i < 3; i++) {
    printf("%s %d %d\n", class[i].name, class[i].age, class[i].score);
}
```

**结构体数组 + for 循环 = 批量处理数据的标配组合**。比如求全班平均分：

```c
int sum = 0;
for (int i = 0; i < 3; i++) {
    sum += class[i].score;
}
printf("平均分: %.1f\n", sum / 3.0);
```

## 二、结构体嵌套

结构体里的成员，也可以是另一个结构体。

```c
struct Date {
    int year;
    int month;
    int day;
};

struct Student {
    char name[20];
    int  score;
    struct Date birthday;   // 成员是结构体！
};
```

访问时**逐层点下去**：

```c
struct Student s = {"张三", 95, {2006, 3, 15}};

printf("%d\n", s.birthday.year);   // 2006
s.birthday.month = 5;              // 修改嵌套成员
```

初始化时内层也用花括号：`{2006, 3, 15}` 是给 `birthday` 这个成员的值。

### 什么时候用嵌套？

当一组字段**自己就是一个整体概念**时：
- 学生的"生日" = 年+月+日 → 打包成 `Date`
- 矩形的"左上角坐标" = x+y → 打包成 `Point`
- 订单的"收货地址" = 省+市+街道 → 打包成 `Address`

好处：概念清晰、可复用（`Date` 可以同时用于学生、老师、员工）。

## 三、完整例子

```c
#include <stdio.h>

struct Date {
    int year, month, day;
};

struct Student {
    char name[20];
    int  score;
    struct Date birthday;
};

int main(void) {
    struct Student class[3] = {
        {"张三", 95, {2006, 3, 15}},
        {"李四", 88, {2007, 7, 1}},
        {"王五", 77, {2006, 12, 30}}
    };

    // 找出成绩最高的学生，打印其完整信息（含生日）
    int best = 0;
    for (int i = 1; i < 3; i++) {
        if (class[i].score > class[best].score) {
            best = i;
        }
    }

    printf("最高分: %s, %d 分, 生日 %d-%02d-%02d\n",
           class[best].name,
           class[best].score,
           class[best].birthday.year,
           class[best].birthday.month,
           class[best].birthday.day);
    return 0;
}
```

> `%02d` 表示"至少 2 位数字，不足补 0"，输出 `2006-03-15` 这种整齐格式。

| 知识点 | 语法 | 记忆点 |
|--------|------|--------|
| 结构体数组 | `class[i].member` | 先取下标，再点成员 |

| 嵌套初始化 | `{"张三", 95, {2006,3,15}}` | 每层结构体一层花括号 |
