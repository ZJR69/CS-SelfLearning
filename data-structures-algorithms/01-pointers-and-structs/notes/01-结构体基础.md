# 01 结构体基础

## 一、为什么需要结构体？

先看一个场景：

你要管理 3 个学生的信息——每个学生有：**姓名、年龄、成绩**。

如果用普通变量，得这么写：

```c
char name1[20], name2[20], name3[20];
int  age1,    age2,    age3;
int  score1,  score2,  score3;
```

问题很明显：
- 变量数量爆炸（3 个学生 × 3 个字段 = 9 个变量）
- 字段之间**没有关联**——`age2` 和 `score2` 只是名字像，编译器不知道它们属于同一个人
- 如果要做"按成绩排序学生"这种操作，几乎写不出来

**结构体（struct）就是解决这个问题的：把几个相关的变量"打包"成一个整体。**

---

## 二、结构体 = 自定义的"数据类型"

C 语言本身有 `int`、`char`、`float` 这些"内置类型"。结构体的本质是：**你自己发明一种新的类型**。

比如你想发明一种类型叫"学生"，它内部装三个东西：姓名、年龄、成绩。这就是结构体。

### 定义语法

```c
struct Student {
    char name[20];
    int  age;
    int  score;
};
```

逐行解读：
- `struct` —— 关键字，告诉编译器"我要定义一个结构体"
- `Student` —— 你给这个新类型起的名字（首字母大写是约定俗成的好习惯）
- `{ ... }` —— 里面列出这个结构体包含哪些字段（叫"成员"）
- `;` —— **注意末尾的分号不能少！** 这是新手最容易踩的坑

定义完之后，`struct Student` 就是一个新类型，地位和 `int` 一样。可以用它声明变量：

```c
struct Student s1;   // 声明一个 Student 类型的变量 s1
struct Student s2;   // 再声明一个 s2
```

> ⚠️ 注意：类型名是 `struct Student`（两个词），不是 `Student`。C 语言里光写 `Student` 编译器不认。
> （C++ 里可以省略 `struct`，但咱们学的是 C，要写全。）

---

## 三、怎么用？—— 访问成员 `.`

定义了变量之后，怎么读/写里面的字段？用 **点操作符 `.`**：

```c
s1.age = 18;              // 给 s1 的 age 赋值
s1.score = 95;            // 给 s1 的 score 赋值
strcpy(s1.name, "张三");   // 字符串数组要用 strcpy，不能直接 = 赋值

printf("%s %d %d\n", s1.name, s1.age, s1.score);
```

**记忆口诀**：`变量.成员` —— "这个变量的某个成员"。

---

## 四、初始化的几种方式

### 方式 1：定义时整体赋值（用花括号）

```c
struct Student s1 = {"张三", 18, 95};
```

> 顺序必须和结构体定义里成员的顺序一致：先 name、再 age、再 score。

### 方式 2：定义后再逐个赋值

```c
struct Student s2;
s2.age = 17;
s2.score = 88;
strcpy(s2.name, "李四");
```

### 方式 3：指定成员赋值（C99，推荐，最不容易出错）

```c
struct Student s3 = {.name = "王五", .age = 19, .score = 77};
```

好处：顺序无所谓，且一眼看出哪个值给哪个字段。

---

## 五、一个完整可运行的例子

```c
#include <stdio.h>
#include <string.h>

struct Student {
    char name[20];
    int  age;
    int  score;
};

int main(void) {
    struct Student s1 = {"张三", 18, 95};
    struct Student s2 = {.name = "李四", .age = 17, .score = 88};

    printf("学生1: %s, %d 岁, 成绩 %d\n", s1.name, s1.age, s1.score);
    printf("学生2: %s, %d 岁, 成绩 %d\n", s2.name, s2.age, s2.score);

    // 修改某个字段
    s1.score = 100;
    printf("修改后学生1成绩: %d\n", s1.score);

    return 0;
}
```

输出：
```
学生1: 张三, 18 岁, 成绩 95
修改后学生1成绩: 100
```

---

## 六、结构体变量之间可以直接赋值

这是个很方便的特性：

```c
struct Student s1 = {"张三", 18, 95};
struct Student s2;
s2 = s1;   // 整体赋值，s2 现在内容跟 s1 完全一样
```

> 注：对于含字符数组（如 `name[20]`）的结构体，整体赋值是 OK 的，编译器会帮你逐字节复制。
> 但如果结构体里含**指针**指向动态内存，直接赋值会出问题（浅拷贝问题）——这个等学指针后再讲。

---

## 七、小结一句话

> **结构体 = 自己造一个新类型，把相关数据打包成一个整体。访问内部字段用 `.`。**
