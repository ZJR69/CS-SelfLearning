# 07 指针 + 结构体：合体技

> 两大块知识都学完了，这一章看它们怎么组合——这是实际项目里最常见的用法。

---

## 一、指向结构体的指针

和普通变量一样，结构体也有地址，也可以用指针指向：

```c
struct Student {
    char name[20];
    int  age;
    int  score;
};

struct Student s = {"张三", 18, 95};
struct Student *p = &s;    // p 是指向结构体的指针
```

### 通过指针访问成员的两种方式

**方式 1：先解引用，再点成员**

```c
printf("%d\n", (*p).score);   // 95
```

> ⚠️ 括号**不能省**！`.` 的优先级比 `*` 高，`*p.score` 会被理解成 `*(p.score)`，直接报错。

**方式 2：`->` 操作符（推荐，专门为此发明）**

```c
printf("%d\n", p->score);     // 95 —— 等价于 (*p).score
p->age = 19;                  // 写也行
strcpy(p->name, "张四");      // 数组成员照样用 strcpy
```

**记忆口诀：`指针->成员`，`变量.成员`。** 看到 `->` 就知道左边一定是个指针。

## 二、为什么结构体传参几乎总用指针？

### 原因 1：避免整体拷贝（效率）

```c
void print_student(struct Student s) {   // 传值：整个结构体拷贝一份
    printf("%s %d\n", s.name, s.age);
}
```

结构体可能很大（想象一下含 10 个成员的结构体），每次调用都复制一份，浪费。

```c
void print_student(const struct Student *p) {   // 传指针：只复制 8 字节的地址
    printf("%s %d\n", p->name, p->age);
}
```

> `const` 表示"我只看不改"——打印函数加上它是好习惯，防止误改。

### 原因 2：想改原件就必须传指针

```c
void add_score(struct Student *p, int delta) {
    p->score += delta;      // 改的是原件
}

int main(void) {
    struct Student s = {"张三", 18, 95};
    add_score(&s, 5);
    printf("%d\n", s.score);   // 100
}
```

### 传参规律总结（和 int 版完全同构）

| 目的 | 写法 |
|------|------|
| 只读 | `void f(const struct Student *p)` |
| 要修改 | `void f(struct Student *p)` |
| 小结构体且确定不改 | 传值也行，但指针更通用 |

## 三、函数返回结构体指针

```c
struct Student *find_best(struct Student class[], int n) {
    int best = 0;
    for (int i = 1; i < n; i++) {
        if (class[i].score > class[best].score) best = i;
    }
    return &class[best];     // 返回数组里某个元素的地址
}

int main(void) {
    struct Student class[3] = {
        {"张三", 18, 95}, {"李四", 17, 88}, {"王五", 19, 77}
    };
    struct Student *top = find_best(class, 3);
    printf("最高分: %s %d\n", top->name, top->score);   // 张三 95
    top->score = 100;   // 注意：这改的是数组里的原件！
}
```

> ✅ 返回**数组元素**的地址是安全的（数组在 main 里活着）。
> ❌ 返回**函数内局部结构体**的地址是灾难（和第 06 章的坑一样）。

## 四、动态创建结构体：malloc（了解即可）

前面所有变量都是"编译时就定好大小和数量"。如果要"运行时才决定创建几个学生"，就需要动态内存：

```c
#include <stdlib.h>

struct Student *p = malloc(sizeof(struct Student));  // 向系统申请一块内存
if (p == NULL) {          // 申请可能失败，养成检查习惯
    return 1;
}
strcpy(p->name, "动态学生");
p->age = 20;
p->score = 90;

/* 使用 ... */

free(p);                  // 用完必须归还！否则内存泄漏
p = NULL;                 // 归还后立刻置空，防悬空指针
```

要点：
- `malloc(字节数)` 申请内存，返回地址；`sizeof` 帮你算字节数
- **每个 malloc 必须配一个 free**，借了要还
- free 之后指针变悬空，置 NULL 是好习惯

## 五、预告：结构体 + 指针 = 数据结构的起点

如果结构体里放一个**指向同类型结构体的指针**：

```c
struct Node {
    int data;
    struct Node *next;    // 指向下一个节点
};
```

这就是**链表**——数据结构课的开门砖。你在爬山/退火算法、数独项目里如果见到类似的自引用结构，现在知道它的原理了。

---

## 六、一句话小结

> **结构体指针用 `->` 访问成员。传参用指针：只读加 const，要改就不加。返回指针只返回"还活着的"内存。**
