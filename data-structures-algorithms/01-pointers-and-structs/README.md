# 单元：指针与结构体（Pointers & Structs）

- 所属课程：数据结构与算法
- 状态：🟡 进行中
- 开始日期：2026-10-12　完成日期：

## 学习目标

1. 掌握结构体的定义、初始化（三种方式）、`.` 访问成员
2. 掌握结构体数组与嵌套结构体
3. 建立"内存 = 带地址的柜子"心智模型，熟练使用 `&` 取地址、`*` 解引用
4. 掌握指针两大用途：函数传参修改原件、指针与数组的关系
5. 掌握结构体指针 `->`、`const` 只读传参、malloc/free 动态内存

## 前置要求

- C 语言基本语法（变量、数组、函数、循环）
- 无其他前置，零基础友好

## 自测清单

- [ ] 能不查资料定义结构体，三种初始化方式都会
- [ ] 知道 `变量.成员` 和 `指针->成员` 的区别与等价关系 `(*p).x`
- [ ] 能解释为什么 `swap(a,b)` 失败而 `swap(&a,&b)` 成功
